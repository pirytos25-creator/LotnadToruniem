Fotorealistyczny 3D

Prawdziwa fotogrametria Google: każda kamienica, gotycki szczyt, drzewo i samochód tak, jak wyglądają naprawdę. Wklej darmowy token Cesium ion (bez karty) albo klucz Google Maps Platform.

Najprościej: darmowy token Cesium ion (bez karty, ok. 3 minuty)
  1. Załóż darmowe konto na ion.cesium.com/signup (plan Community).
  2. W Asset Depot otwórz „Google Photorealistic 3D Tiles” i kliknij Add to my assets.
  3. W Access Tokens skopiuj Default Token (zaczyna się od eyJ) i wklej go powyżej.
Albo klucz Google Maps Platform
  1. Wejdź na console.cloud.google.com → Map Tiles API i zaloguj się kontem Google.
  2. Utwórz projekt (np. „Lot nad Toruniem”) i kliknij Włącz przy Map Tiles API. Google poprosi o podpięcie karty do rozliczeń, ale darmowy limit w zupełności wystarcza do latania.
  3. Wejdź w Dane logowania → Utwórz dane logowania → Klucz API i skopiuj klucz.
  4. Dla bezpieczeństwa ogranicz klucz do Map Tiles API i do adresu Twojej strony (np. twojlogin.github.io/*).

Klucz zostaje tylko w tej przeglądarce (localStorage). Nie trafia do repozytorium.
